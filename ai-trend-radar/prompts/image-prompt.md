# Image Generation Prompt

이미지 아이디어가 아니라 실제 이미지 생성 프롬프트를 만든다.

필요한 경우 아래 프롬프트를 포함한다.

- 썸네일용 이미지 프롬프트
- 본문 카드용 이미지 프롬프트
- 전환컷 배경용 이미지 프롬프트
- 릴스 썸네일용 이미지 프롬프트

규칙:

- 이미지 안에 텍스트를 넣지 않는다.
- 이미지 안에 로고를 넣지 않는다.
- 실존 인물의 얼굴을 직접 생성하지 않는다.
- 특정 브랜드 로고를 생성하지 않는다.
- 한국어 제목을 얹을 수 있는 여백을 남긴다.
- 다크, 하이테크, 시네마틱, 뉴스 매거진, 프리미엄 에디토리얼 톤을 기본으로 한다.
- 9:16 또는 4:5 인스타 비율을 고려한다.
- 복잡한 장면보다 한눈에 이해되는 강한 오브젝트 중심으로 작성한다.

예시 톤:

```txt
A cinematic vertical editorial image of a futuristic AI workspace, multiple glowing screens collapsing into one clean command center, dramatic lighting, black background, high contrast, premium tech magazine style, no text, no logos, leave empty space at the top and bottom for Korean headline overlay, 9:16 composition
```
