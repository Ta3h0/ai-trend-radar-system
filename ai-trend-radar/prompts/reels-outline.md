# Reels Outline Prompt

릴스 후보는 5~12초 안에 핵심 반응을 만들 수 있어야 한다.

반드시 포함한다.

- 원본 영상 링크
- 공식 영상인지 여부
- 개인 업로드인지 여부
- 사용 가능성 판단
- 추천 캡처 구간
- 영상 없이 대체 제작 가능한지
- 장면별 구성안
- CTA
- 캡션 초안
- 출처
- 리스크

영상 사용 판단:

```txt
A. 사용 가능성 높음
- 공식 프레스 영상
- 공식 유튜브/공식 X/공식 블로그의 공개 데모
- 임베드/공유 목적이 명확한 자료

B. 확인 필요
- 뉴스 영상
- 개인 유튜브 리뷰 영상
- 인스타/틱톡 재업로드 영상

C. 사용 금지
- 워터마크 있는 타 계정 영상
- 출처 불명 짜깁기 영상
- 개인이 편집한 쇼츠/릴스
```
